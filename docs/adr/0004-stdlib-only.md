# 4. Только стандартная библиотека

## Контекст

Привычный выбор для HTTP — `requests` или `httpx`. Но для утилиты, которую
запускают на своём компьютере, важнее, чтобы она работала без установки
зависимостей. Кроме того, `requests` по умолчанию просит gzip и сам
распаковывает ответ, а его `elapsed` вводит в заблуждение (см. ADR 1 и 3).

## Решение

`urllib.request` из стандартной библиотеки. Python 3.10+ — и больше ничего.
Зависимости разработки (pytest, ruff, mypy) живут в группе `dev` и для
запуска не нужны.

## Последствия

- Запуск: `uv run netspeed URL` или `pip install .`: ставится только сам
  пакет, без сторонних зависимостей.
- Нет пула соединений: каждый запрос открывает новое TCP/TLS-соединение.
  Для этой задачи так даже честнее: каждый из 10 запросов — полноценный
  запрос, как у пользователя.
