# netspeed

CLI-утилита: скачивает один URL N раз подряд (по умолчанию 10) и печатает среднее время
запроса, объём и скорость в МБ/с. Только стандартная библиотека, Python 3.10+.

Глоссарий: `CONTEXT.md` — его словами пишутся код, тесты и доки. Решения: `docs/adr/` — перед
изменением области читай ADR, которые её касаются; пиши новый, когда делаешь выбор, который
компетентный инженер мог бы сделать иначе.

## Команды

```bash
uv sync                          # venv + dev-группа (pytest, ruff, mypy, pre-commit)
uv run netspeed URL [-n 10]      # сам инструмент
uv run pytest                    # тесты; один: uv run pytest tests/test_x.py -k name
uv run ruff check . && uv run ruff format --check .
uv run mypy                      # strict; конфиг в pyproject.toml
uv run pre-commit install        # один раз на клон
```

## Структура

```
src/netspeed/
  measure.py   fetch(url, timeout) -> Sample; FetchError — любой непригодный замер
  stats.py     summarize(samples) -> Summary
  cli.py       argparse, серия запросов, вывод, коды выхода 0/1/2
tests/
  conftest.py  локальный HTTP-сервер: маршрут на каждый сценарий (медленное тело, обрыв, ошибки)
docs/adr/      решения
```

## Инварианты — не ломать

- Время замера — до последнего байта тела, не до заголовков (ADR 1).
- Скорость — суммарный объём / суммарное время, не среднее скоростей (ADR 2).
- Оборванное или пустое тело — `FetchError`, а не замер (ADR 3).
- Никаких сторонних runtime-зависимостей: `dependencies = []` (ADR 4).

## Конвенции

- `cli.py` только разбирает аргументы, печатает и выбирает код выхода; логика — в `measure`
  и `stats` и тестируется без CLI.
- Ожидаемые ошибки — `FetchError` с сообщением, по которому пользователь может действовать;
  `except Exception` не ловить. Трейсбек на пользовательском вводе — баг.
- Каждая строка вывода печатается с `flush=True`: stdout и stderr идут в одну консоль.
- Новый сценарий сети — новый маршрут в `tests/conftest.py`, а не мок `urllib`.
- Тексты для пользователя и комментарии — на русском.
- Код пишется сразу под конфиг ruff (line-length 100), чтобы формат на pre-commit был no-op.
