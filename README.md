# netspeed

Скачивает файл 10 раз подряд и печатает среднее время запроса, объём и скорость в МБ/с.

```bash
git clone https://github.com/delawer33/netspeed.git && cd netspeed
uv run netspeed https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57752/land_shallow_topo_8192.tif
```

```
[ 1/10]    27.80 МБ   23.313 с      1.19 МБ/с
[ 2/10]    27.80 МБ   31.625 с      0.88 МБ/с
...
[10/10]    27.80 МБ   12.239 с      2.27 МБ/с

Успешных запросов:  10 из 10
Скачано:            277.98 МБ (277979680 байт)
Среднее время:      22.867 с
Скорость:           1.22 МБ/с (9.7 Мбит/с)
```

Нужен Python 3.10+. Сторонних зависимостей нет. Без [uv](https://docs.astral.sh/uv/):
`pip install .`, затем `netspeed URL`.

## Параметры

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `URL` | | `http(s)://` адрес файла, лучше от 10 МБ |
| `-n`, `--requests` | 10 | число запросов подряд |
| `--timeout` | 60 | предел на один запрос, с |

Коды выхода: 0, если все запросы успешны; 1, если часть упала или серию прервали Ctrl+C; 2, если
успешных нет.

## Как считается

- время запроса: от отправки до последнего байта тела, не до заголовков ([ADR 1](docs/adr/0001-time-to-last-byte.md))
- скорость: суммарный объём / суммарное время, не среднее скоростей ([ADR 2](docs/adr/0002-ratio-of-sums.md))
- оборванное или пустое тело считается ошибкой, а не замер ([ADR 3](docs/adr/0003-honest-bytes.md))
- запросы идут без сжатия и с `Cache-Control: no-cache`
- МБ = 10⁶ байт; в скобках та же скорость в Мбит/с

На прогоне выше среднее скоростей дало бы 1,49 МБ/с вместо 1,22.

Это скорость до конкретного сервера. Для замера канала до провайдера берите файл с ближнего CDN.

## Ограничения

- одно соединение, а speedtest-сервисы качают в 4–16 потоков, поэтому их цифра выше
- рукопожатие DNS и TCP/TLS входит в каждый запрос: до сервера NASA это ~1 с из 12–48 с
- меряется только загрузка, отдача — нет
- `no-cache` лишь просьба, CDN может её проигнорировать
